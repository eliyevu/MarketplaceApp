# Marketplace App

A mobile marketplace prototype built with React Native, Expo,
TypeScript and React Navigation.

## Features

- Login and Sign Up screens
- Stack navigation
- Bottom tab navigation
- Product feed
- Product search
- Cart screen
- Profile screen
- Responsive mobile UI

## Tech Stack

- React Native
- Expo
- TypeScript
- React Navigation

## Getting Started

### 1. Clone the repository

git clone YOUR_REPOSITORY_URL

### 2. Navigate into the project

cd MarketplaceApp

### 3. Install dependencies

npm install

### 4. Start the Expo development server

npx expo start

### 5. Run on a device

Scan the QR code using Expo Go.
